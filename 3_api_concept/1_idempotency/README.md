## Question
1_idempotency: ความเข้าใจเรื่อง Idempotency
![](/assets/q_idempotency.png)
## Response Section

Idempotency คือการที่ Request เดิมถูกเรียกซ้ำหลายครั้ง แต่ผลลัพธ์ต่อ State ของระบบควรเหมือนกับการทำ Request สำเร็จเพียงครั้งเดียว

ตัวอย่างเช่น ใน Database มีข้อมูลของผู้ใช้งานชื่อ "จตุพร" และต้องการลบข้อมูลดังกล่าว

มีการเรียก Request เดิมหลายครั้ง:

DELETE จตุพร → ข้อมูลจตุพรถูกลบออกจากระบบ

DELETE จตุพร → ข้อมูลจตุพรไม่มีอยู่แล้ว จึงไม่มีข้อมูลเพิ่มเติมที่ต้องลบ

DELETE จตุพร → ข้อมูลจตุพรยังคงไม่มีอยู่ และไม่มีข้อมูลอื่นได้รับผลกระทบ

ถึงแม้ Request จะถูกเรียกหลายครั้ง แต่ State สุดท้ายของระบบยังคงเหมือนกับการเรียกเพียงครั้งเดียว คือข้อมูลของจตุพรไม่มีอยู่ในระบบ

ดังนั้น Idempotency คือ การเรียก Operation เดิมซ้ำหลายครั้งแล้ว State สุดท้ายของระบบยังคงเหมือนกับการเรียก Operation นั้นสำเร็จเพียงครั้งเดียว
